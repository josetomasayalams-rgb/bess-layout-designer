# Technical Docs Writer Skill

Use this skill for:
- README
- technical assumptions
- equipment documentation
- layout rule documentation
- limitation notes
- engineering disclaimers
- roadmap

## Documentation rules
- Be technically precise.
- Separate certified values from assumptions.
- Do not overclaim.
- Use tables for equipment data.
- Add a limitation section to every engineering document.
- Mark all spacing and routing values as preliminary unless confirmed by source.
